## 数据说明

- 文本提取自游戏静态数据表,按「说话人 + 台词」结构化(无说话人的行按旁白缩进)。
- 简中文本;整理日期 2026-11-09,对应 Table 版本 1195672。
- 主线剧情因游戏资源机制限制,暂无法精确挂接章节归属与逐句说话人
  (技术原因见工具仓库的 `blocked.md`)。
- 富文本标签(color/size)已剥离,`{}` 占位符保留原样。
